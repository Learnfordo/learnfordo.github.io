## 📚 arXiv 论文精选

### 1. AURORA-LM：连续潜空间扩散语言模型

**论文：** [arXiv:2608.02602](https://arxiv.org/abs/2608.02602)

提出一种将文本编码为高容量连续潜空间表示、再用扩散模型（flow matching）建模其分布的新范式。采用基于 Query 的编码器-解码器将文本组织为前缀对齐的潜序列，Block-causal 扩散 Transformer 从左到右生成块并并行去噪。在 OpenWebText 自由生成和 XSum 摘要任务上达到同类连续/扩散语言模型最佳表现，并扩展至 1B 参数。

### 2. GradCuit：梯度归因驱动的测试时潜在推理

**论文：** [arXiv:2608.02585](https://arxiv.org/abs/2608.02585)

在 Transformer 层间插入可优化潜状态，使每个 continuation token 的 log-probability 都有到所有前序潜状态的可微路径，实现奖励加权梯度直接归因到潜变量。在 5 个指令微调模型、3 个推理基准上平均准确率 64.5%，超过 Chain-of-Thought 提示 6.6 个百分点。梯度分析显示潜影响集中在推理连接 token 上，早期至中间 Transformer 层是最有效的优化空间。

### 3. UEmbed：统一稀疏与稠密多模态嵌入

**论文：** [arXiv:2608.02583](https://arxiv.org/abs/2608.02583)

提出 Decoder-only 多模态嵌入模型，在一个前向传播中同时产生稀疏词法和稠密表示。通过追加 N 个可学习特殊 token 并将词表划分为 N 个不相交子集，每个 token 的因果隐状态预测其子集的稀疏权重。发布 2B/4B/9B 三个规模，UEmbed-9B 在 MMEB-v2 上达到 71.8（稠密）和 71.0（稀疏）。

### 4. AtumAI：智能体生成数据中心控制面策略

**论文：** [arXiv:2608.02569](https://arxiv.org/abs/2608.02569)

提出一个框架，使 Agentic AI 能形式化、可迁移、系统化地生成数据中心控制面策略。通过"数据中心任务编译器"将自然语言目标编译为机器可检查的形式化规约，再用进化设计发现循环（扩散模型+进化算法+代理模型）搜索设计空间。在负载放置、资源伸缩和功耗管理三个任务上，生成的策略持续超越专家工程基线。

### 5. PRECOG：边缘语言模型的结构化记忆——O(1) 状态注入

**论文：** [arXiv:2608.02560](https://arxiv.org/abs/2608.02560)

利用 State-Space Model (SSM) 固定大小、位置无关的循环隐状态特性，提出 PRECOG（预计算上下文注入）检索机制，将预填成本从 O(L_context) 降至每次查询 O(1)。该方法将 SSM 的隐状态作为可预先计算的检索表示，为边缘设备上的 LLM 持久上下文和语料检索提供了新范式。

### 6. CoWAM：双臂机器人策略选择性干预的协调合约

**论文：** [arXiv:2608.02578](https://arxiv.org/abs/2608.02578)

为 World Action Models (WAMs) 增加选择性干预层，通过同步、角色兼容和碰撞收敛三种协调合约，仅在替代动作满足所有约束时才干预策略输出。在 8 个双臂仿真任务上，协调有效选择率提升 16.7 个百分点，闭环成功率提升 9.6 个百分点，有害干预低于 1%。
