## 📰 行业新闻

### Anthropic 将 Claude Chrome 扩展升级为「Claude Cowork」

Anthropic 更新了其 Chrome 浏览器扩展，侧边栏聊天现在会保存到历史记录中，用户可以在桌面端、网页端或移动端继续对话。Claude Cowork 面向 Max 和 Team 用户开放，Pro 用户将在未来几周内获得 access。这标志着 AI 助手正在更深地嵌入浏览器工作流。

→ [The Verge](https://www.theverge.com/ai-artificial-intelligence)

### OpenAI 开始在 ChatGPT 中测试广告

OpenAI 官方博客确认正在 ChatGPT 中测试广告功能。这是 ChatGPT 从纯对话工具向商业平台转型的重要信号。同时 OpenAI 还发布了「企业如何将 AI 投入实践」的企业应用报告。

→ [OpenAI Blog](https://openai.com/blog)

### Meta 开源 Muse Glimmer：30B 参数智能体优化模型

Meta 以 Apache 2.0 许可证开源了 Muse Glimmer，一个 300 亿参数、专为 AI Agent 优化的模型。这标志着 Meta 在 Agent 领域回归开源路线，为社区提供了一个强大的开源 Agent 基座模型。

→ [VentureBeat](https://venturebeat.com/technology/meta-returns-to-open-source-with-muse-glimmer-an-apache-2-0-licensed-30b-parameter-ai-model-optimized-for-agents-available-now)

### Mistral AI 计划到 2030 年建设 1GW 欧洲算力

法国 AI 公司 Mistral 宣布三部分基础设施扩展计划：区域推理端点（可选欧洲或美国运行）、有正常运行时间保证的 Priority Tier、以及欧洲企业联盟的多年度算力承诺。目标是在 2027 年底前支持 200MW、2030 年底前达到 1GW 算力规模。

→ [VentureBeat](https://venturebeat.com/infrastructure/mistral-ai-wants-to-build-1-gigawatt-of-european-compute-by-2030-and-lock-in-customers-now)

### OpenAI 发布 GPT-5.6 Cyber 网络安全模型

OpenAI 推出面向网络安全场景的 GPT-5.6 Cyber 模型，降低了拒绝率，在高级网络安全任务上达到 95% 完成率。同时 OpenAI 仍在扩展 Daybreak 系列模型，并将其部署到 AWS。

→ [VentureBeat](https://venturebeat.com/technology/openai-launches-gpt-5-6-cyber-with-reduced-refusals-95-completion-on-advanced-cybersecurity-tasks)

### Anthropic 研究院发布多智能体系统安全报告

Anthropic 前沿红队于 8 月 13 日发布最新研究，分析了新兴多智能体系统中的模式与问题，为 Agent 系统的安全部署提供了重要参考。

→ [Anthropic Research](https://www.anthropic.com/research/multiagent-systems)

## 📚 arXiv 论文精选

### 1. AVA-Encoder：面向智能体的原生视频表征学习

**论文编号：** [2608.12313](https://arxiv.org/abs/2608.12313)

提出 Agentic Video Auto-Encoder (AVA-Encoder) 框架，将视频转化为知识图谱表示并重建为视频，使 AI Agent 能够理解、查询和编辑电影级视频内容。实验显示比最强外部基线提升 20.7 个百分点，且系统提示 token 减少 74.3%。

### 2. AI4AI：测试时强到弱能力迁移

**论文编号：** [2608.12307](https://arxiv.org/abs/2608.12307)

研究强模型如何在推理时（而非训练时）构建 harness 来帮助弱模型更好地完成任务。在四个心智理论基准上，平均性能从 0.49 提升至 0.91，近乎翻倍。核心增益来自将不稳定推理卸载到确定性代码中。

### 3. VAKRA：评估 API 与知识检索的多跳推理能力

**论文编号：** [2608.12282](https://arxiv.org/abs/2608.12282)

IBM 团队提出 VAKRA 基准，包含 8000+ 可执行 API、覆盖 62 个领域，评估 Agent 在工具使用策略约束下的多跳推理能力。最强模型在单跳任务上仅达 70.4%，多跳任务降至 50% 左右，策略约束问题准确率低至 2.4%。

### 4. Structural Silence：AI 基础设施对欠代表语言的系统性失败

**论文编号：** [2608.12278](https://arxiv.org/abs/2608.12278)

以孟加拉语为例，揭示 AI 基础设施的结构性不平等：孟加拉语占全球人口近 4%，但网页内容占比不足 0.5%；在主流多语言语料库中英语与孟加拉语训练 token 差距达 67:1。论文主张将数据稀缺视为结构性障碍而非技术限制。

### 5. DreamFly：因果记忆与滚动视野扩散规划的空中视觉语言导航

**论文编号：** [2608.12308](https://arxiv.org/abs/2608.12308)

提出基于扩散模型的空中视觉语言导航框架，引入因果对齐历史记忆和「规划-K步、执行1步」的滚动视野策略，在 OpenFly 基准上达到 32.04%/29.46% 的成功率，全面超越对比方法。

### 6. Beyond Trial-and-Error：智能体优化图像到视频的提示 adherence

**论文编号：** [2608.12290](https://arxiv.org/abs/2608.12290)

提出「智能体自我改进」框架，将视频合成重构为闭环目标导向优化。结合多模态 LLM 的迭代提示优化和贝叶斯优化，人工偏好评估中胜率高达 69%，推动了视频生成从试错走向可靠生产工具。

### 7. 使用 RAG 和大模型构建动态主逻辑模型知识图谱

**论文编号：** [2608.12304](https://arxiv.org/abs/2608.12304)

利用 RAG 和 LLM 自动从技术文档构建 Dynamic Master Logic (DML) 模型并表示为知识图谱，应用于核电站低压冷却剂注入系统，实现了跨层级精度、召回率和逻辑门一致性的一致性重建。
