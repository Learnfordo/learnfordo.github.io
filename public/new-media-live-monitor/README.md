# 中国新媒体大会 · 直播监控 H5 Demo

参考“大会集锦”设计图实现的移动端 Demo，并借鉴 `live-companion`（直播搭子）的“摘要、高光统一上看板”思路。

## 直接预览

双击 `index.html` 即可，无需安装依赖、无需构建、无需联网。请保留 `mock-data.js` 和 `assets/` 的相对位置。

页面支持：

- **最新动态**：默认 Tab，按时间倒序展示大会动态，混排文字、图片和视频。
- **高光图片**：双列图片卡片，点击全屏预览，支持上一张/下一张及键盘方向键。
- **高光视频**：视频合集卡片，点击弹层播放；当前所有卡片共用一段 8 秒本地演示片。
- 返回、分享、Tab 键盘导航、移动端安全区、桌面端居中预览。
- 可通过 `index.html#photos` 或 `index.html#videos` 直接打开指定 Tab；无 Hash 时默认展示最新动态。

> 页面中的时间、文案、照片均为演示内容，不是大会真实监控结果。

## 后续接入建议

第一阶段只固定 UI 和内容结构，下一阶段再将直播搭子能力封装为大会专用专家：

1. **采集与转写**：复用直播搭子的 HLS/FLV 采集、ASR、任务状态与故障恢复。
2. **大会内容生产**：滚动摘要进入“最新动态”；定时取帧/精选帧进入“高光图片”；场景高光切片进入“高光视频”。
3. **统一内容接口**：将 Demo 的三组数据映射为 `timeline / photos / videos`，以内容 ID 幂等更新，避免重复上板。
4. **H5 自动更新**：正式服务提供增量 JSON，前端轮询或通过 SSE 推送；新动态置顶，图片与视频同步聚合。
5. **Octop 专家封装**：新增大会专用 `manifest / SOUL / IDENTITY / SKILL`，保留直播搭子的 cron tick、监控告警、结束收尾和归档能力。
6. **彩排验收**：用真实直播源验证延迟、高光质量、手机兼容性及长时间运行，再接入本次大会正式标题、主视觉和议程。
