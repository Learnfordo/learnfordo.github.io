Transformer：用注意力取代循环的架构

2017 年的一篇论文把序列建模从「逐字串行」改成「全句同时对着看」，此后所有主流大模型与大量感知系统都建在这套骨架上。

最近更新 2026-11-05 17:56

01

概览：一套「用注意力代替记忆」的序列处理逻辑

它是什么、从哪来、为什么重要

Attention

Transformer 是 2017 年由 Google Brain 与 Google Research 团队在论文《Attention Is All You Need》中首次提出的神经网络架构，论文在 NeurIPS 2017 发表，作者共 8 位：Ashish Vaswani、Noam Shazeer、Niki Parmar、Jakob Uszkoreit、Llion Jones、Aidan N. Gomez（当时来自多伦多大学）、Łukasz Kaiser 与 Illia Polosukhin。据 CSDN 上的一篇技术回顾文章记述，完整架构由 Encoder（编码器）与 Decoder（解码器）两部分组成，最初的目标任务是机器翻译。

据 php 中文网的科普文章归纳，Transformer 的核心可以用一句话概括：它用注意力代替记忆，由自注意力机制、多头协同、位置编码、堆叠编码器与掩码解码器五部分组成。从 AI 产品视角看（据 CSDN 一篇面向产品经理的文章），它本质上是一种「通过上下文关系预测下一个 token」的架构，同样也是 OpenAI 的 GPT、Anthropic 的 Claude、Google 的 Gemini 背后的核心技术基础。

与 RNN、LSTM 相比，它的差别不在精度而在信息通路：RNN 必须按时间步逐字传递隐藏状态，训练难以并行，长文本开头的信息传不到结尾；Transformer 让序列中任意两个位置直接建立依赖，训练阶段可以高度并行。代价是自注意力对序列长度的计算与显存复杂度通常是 O(n²)，长上下文、KV Cache、位置外推与推理带宽随之成为工程难点。

02

关键事实

时间、作者、结构、复杂度与边界，一条一条独立成立

  • 发表论文《Attention Is All You Need》于 2017-06 发表，由 NeurIPS 2017 收录。
  • 作者共 8 位，分属 Google Brain、Google Research，其中 Aidan N. Gomez 来自多伦多大学。
  • 结构完整架构为 Encoder + Decoder，最初面向机器翻译；编码器路线演化出 BERT，解码器路线演化出 GPT 系列。
  • 五要素自注意力机制、多头协同、位置编码、堆叠编码器、掩码解码器。
  • 公式注意力按 softmax(QKᵀ/√dk)V 计算，缩放因子 √dk 用于避免 Q 与 K 的点积过大导致 softmax 趋于平缓。
  • 复杂度Self-Attention 对序列长度的计算与显存复杂度通常为 O(n²)。
  • 并行性任意 token 之间可直接交互，训练阶段可高度并行，结构规整、适合 GPU/TPU 矩阵运算。
  • 边界Transformer 是神经网络架构；LLM 是用其解码器加海量文本预训练出的巨型语言模型，两者不能划等号。
  • 外延GPT-4、Claude、Llama、Qwen 都建立在它之上；自动驾驶感知、语音识别、蛋白质结构预测、代码生成也在用它处理长距离依赖。

04

时间线

从架构奠基、路线分叉到规模扩张

2017
  • 2017-06 Google Brain 与 Google Research 团队发表《Attention Is All You Need》，NeurIPS 2017 收录，完整架构为 Encoder + Decoder，目标是机器翻译。
  • 2018-06 GPT-1 发布，参数 1.17 亿，只用 Transformer 的 Decoder，证明「预训练 + 微调」可以完成多种语言任务，但能力普通、未出圈。
  • 2018-10 BERT 发布，纯编码器、双向理解，刷新 11 项 NLP 榜单，预训练—微调范式正式确立，谷歌搜索随后大规模用上 BERT。
  • 2019 GPT-2 发布，15 亿参数，第一次展现零样本能力：不给新任务的微调数据也能干活。
  • 2020-05 GPT-3 发布，1750 亿参数，规模法则与少样本学习成为讨论焦点；但它是补全文本的模型，并非为对话设计。
  • 2020 Vision Transformer（ViT）把 Transformer 从自然语言处理扩展到计算机视觉，通过图像 Patch 划分实现全局上下文建模。
  • 2021-06 Llion Jones 宣布离开谷歌，至此 Transformer 论文的八位共同作者已全部离开谷歌。
  • 2024-05 DeepSeek V2 发布，提出多头潜在注意力机制（MLA），把 KV 缓存压到传统 MHA 的 1/4 至 1/8，与 MoE 结合后 KV 缓存减少约 93.3%。
  • 2024-12-26 DeepSeek V3 首次发布并开源，采用 MoE 与 MLA，总参数 671B，激活参数 37B，训练成本约 557 万美元。
  • 2025-09-01 《人工智能生成合成内容标识办法》正式施行，要求 AI 生成内容强制添加显式与隐式标识。
  • 2026-02-02 OFweek 传感器网发文拆解 Transformer 在自动驾驶中的角色：全局感受野、多传感器 token 化融合、长时序轨迹预测与端到端统一骨干。
  • 2026-06 Noam Shazeer 宣布离开 Google 加入 OpenAI，引发 Alphabet 股价一度暴跌超 7%，市值蒸发逾 3000 亿美元。

06

术语卡

读 Transformer 绕不开的六个词

自注意力 SELF-ATTENTION

让每个词主动计算自己与句中所有其他词的相关程度，再按权重加权求和。相比 RNN 沿时间步传递隐藏状态，它把任意两位置的路径长度压成常数级。

Q / K / V QUERY·KEY·VALUE

输入分别乘可学习权重矩阵 WQ、WK、WV，得到查询、键、值三组向量。查询问「我想知道什么」，键是「我这里有什么线索」，值是要真正传出去的内容；查询与所有键做点积得匹配分，经 softmax 归一后加权值向量。

多头注意力 MULTI-HEAD

并行跑多个独立注意力头，每个头学习不同的关联模式，再把结果沿特征维度拼接、经一次线性变换压回原维度。作用类似多位专家审同一段文字，最后汇总成更立体的理解。

位置编码 POSITIONAL ENCODING

自注意力本身对词序无感，打乱「猫追老鼠」与「老鼠追猫」的向量顺序可能算出一样的结果。位置编码用正弦与余弦函数生成实值向量，直接加到词嵌入上，等于给每个词发一张带编号的座位卡。

残差与层归一化 RESIDUAL + LAYERNORM

每个子层输出与输入相加（Output = Input + SubLayer(Input)），再经层归一化。残差让信息能直达深层、抑制梯度消失，归一化让数据分布稳定、加速收敛，上百层堆叠因此可行。

KV Cache INFERENCE COST

自回归生成时，已算过的键值会被缓存复用。它是长上下文推理的主要显存开销之一，也是 MLA 这类压缩注意力机制的优化目标。

07

背景脉络

它要解决的，是 RNN 的结构性困境

RNN 是「逐字默读」的人

RNN 的设计只有一个关键：一个带记忆的单元沿时间轴反复复用，每读入 x(t) 就结合上一刻的记忆 h(t-1) 算出这一刻的 h(t)。优点是参数共享、天然有序、理论上可处理任意长度；缺点是 h(t) 依赖 h(t-1)，必须逐步串行计算，训练慢、序列越长越慢，GPU 算力大量闲置。

梯度沿时间连乘，远距离词元学不到

反向传播要沿时间连乘同一个 Jacobian（可理解为 W_hh 的 t 次幂），造成梯度消失或爆炸，远距离的词元学不到。LSTM/GRU 的门控只是缓解，并没有根治。据掘金上的一篇面向工程背景读者的文章，这正是 Transformer 的出场动机。

Transformer 是「同时扫视整页」的编辑

它不做「替换 RNN」这么简单的事，而是让每个位置能直接读取序列中最相关的位置，同时用位置编码保留顺序信息。信息交互从按时间步传递改成任意位置 Attention，训练并行性从低变为高，长距离依赖从弱变为强，代价是二次复杂度。

把这段脉络放到工程语境里看会更清楚。RNN 的单步计算量小、模型轻，在早年算力下是合理选择；但一旦数据规模上去，串行就成了硬约束。Transformer 把「一步算一个词」换成「一次算全句」，正好吃满了 GPU/TPU 的矩阵算力，也因此与后来的 Scaling Law 天然契合——架构简洁让它容易堆到千亿甚至万亿参数，注意力机制让它能从海量数据中提取复杂关联。

横向对比

三条架构分支，以及它与 RNN 的差别

Transformer 三种架构分支对比
架构分支代表模型特点与场景
Encoder-only BERT 双向关注，能看左右两边，擅长理解类任务：搜索、分类、检索
Decoder-only GPT 系列、Llama、Qwen、Claude 单向掩码，只能看上文，擅长生成下一个 token，是当前 LLM 的主流选择
Encoder-Decoder 原始 Transformer、T5、BART 编码器理解输入、解码器条件生成，适合翻译、摘要、问答
  • 信息交互RNN 按时间步传递；Transformer 任意位置直接交互
  • 训练并行RNN 低；Transformer 高，适合 GPU/TPU 矩阵运算
  • 长程依赖RNN 较弱、梯度传播距离长；Transformer 强
  • 主要代价RNN 串行训练慢；Transformer 注意力二次复杂度
  • 易混点Transformer ≠ GPT；注意力 ≠ 自注意力

据游乐网的技术词条提醒，还有两个常见误解值得单独说明。其一，Transformer 与 GPT 是「汽车」和「某品牌轿车」的关系——前者是架构，后者是基于其解码器部分构建的具体模型。其二，「注意力」是更广的概念，指模型聚焦输入特定部分的能力；「自注意力」特指序列内部元素之间的注意力。此外，Transformer 核心层是并行的，但在训练超大模型或处理极长序列时，也可能结合一些循环或递归思想做优化，其根本优势仍然是并行性。

10

观察

以下三条是分析判断，不是材料事实

分析

O(n²) 是这套架构的固有账单，而不是实现瑕疵。序列长度翻倍，注意力计算量随之升至四倍，长上下文、KV Cache 显存、位置外推与推理带宽全都由此派生。MLA、稀疏注意力、FlashAttention 这类工作本质是在同一数学框架内做减法；真正的另一条路是换成线性复杂度的结构。当前判断是：减法的收益已经很清楚，换掉框架的证据还不充分。

分析

Encoder-only / Decoder-only / Encoder-Decoder 的三分法，看似只是剪裁模块，实际决定了产品形态。编码器双向看全句，天然适合检索与分类；解码器单向掩码，天然适合逐字生成。2018 年的分叉之所以重要，是因为押注解码器的路线后来长成了对话产品，而押注编码器的路线沉进了搜索与理解类基础设施——同一种架构，两种商业模式。

分析

八位作者全部离开谷歌、分散到对话、企业 NLP、智能体、生命科学、区块链等多个方向，说明这类基础架构的价值释放主要发生在原机构之外。对产业的含义是：架构一旦公开，竞争焦点就从「谁发明」转到「谁能把它做得更省、更快、更贴合场景」，DeepSeek 用 MLA 与 MoE 压 KV 缓存与训练成本，正是这条逻辑的延续。

11

后续观察

三个值得盯住的变量

01

长上下文的成本曲线

上下文窗口的商业价值取决于单位 token 的推理成本。KV Cache 压缩、稀疏与线性注意力、位置外推能力，这三项里任何一项出现量级改进，都会直接改写长文档、代码库级理解与多轮对话的可用边界。

02

统一骨干能走多远

自动驾驶的实践已经显示，把检测、跟踪、分割、预测放在同一张注意力表示上，能减少工程接口与错误累积。接下来要看的是：这种统一性能否在更多需要多源、高维、长时序数据的领域复现，而不只在感知任务里成立。

03

能力边界而非参数规模

从 GPT-1 到 GPT-3，参数放大带来了零样本与少样本能力；但当规模红利边际递减，讨论重心会转向模型究竟学到了关联还是逻辑。对 Transformer 的质疑，多半不会来自「够不够大」，而来自「够不够准」。
