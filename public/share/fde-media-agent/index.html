01 / 说清楚

一张任务单

做什么、给谁、边界、交回、何时停。别只说“帮我做个 AI 分享”。
先要提纲，再要正文
02 / 拆对了

一条线，还是分头做

能独立完成、能独立验收，才值得拆。步骤环环相扣，就让一个 Agent 连着做。
别按“策划 / 研究 / 写作”硬拆
03 / 验得住

先自检，人拍板

给它一个能自己执行的检查。链接能打开、说法有来源、改完能跑通。
最后一步，永远是人
拿到的东西好不好用，比同时开几个助手更重要。
三个习惯留交接条早点看方向控制并行
